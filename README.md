# iTeaGrow - Research-Project
🌱 Research project focused on enhancing tea cultivation in Sri Lanka through data-driven insights, monitoring, and technological innovation to improve yield and sustainability.

🍃 Tea Leaf Quality Assessment & Environmental Monitoring System

Student ID: IT22197214
Research Project – 2025 July

🌱 Project Overview of component 1

This project aims to develop an AI-powered, non-destructive solution for early detection and monitoring of tea leaf diseases in Sri Lanka. It integrates image-based disease detection with environmental monitoring, providing actionable insights to plantation managers for precise crop management.

🎯 Goals

Detect and classify two main tea leaf diseases.

Recommend suitable treatments or interventions.

Monitor key environmental parameters in real-time.

Provide mobile-friendly deployment for field use.

Support local languages (Tamil/Sinhala) and smallholder farmers.

🛠 Components
1️⃣ Image-Based Leaf Disease Detection

Capture high-resolution images of tea leaves via handheld devices or remote cameras.

Detect disease-affected leaves using computer vision & deep learning.

Train a deep learning model to classify leaf health status.

Recommend disease-specific treatments (fungal, bacterial, nutrient deficiency).

Tech / Tools: TensorFlow / Keras, PyTorch, OpenCV, PIL, Albumentations

2️⃣ Smart Tea Leaf Disease Monitoring

Non-destructive, real-time AI-powered solution.

Identifies visual disease cues: spots, discoloration, texture changes.

Designed for Sri Lankan tea plantations.

Optimized for mobile / low-power edge devices.

Benefits: Early detection, precision management, sustainable agriculture.

3️⃣ Environmental Sensing & Dashboard Integration

Integrate compact IoT sensors for monitoring:
🌡 Temperature | 💧 Humidity | 🌞 Light Intensity | 🌱 Soil Moisture

Stream data to cloud/local DB for continuous logging.

Visualize trends on an intuitive dashboard for data-driven decisions.

Tech / Tools: Raspberry Pi / Arduino, DHT11/DHT22, BMP280, Soil Moisture Sensor, MQTT, Flask/FastAPI, Streamlit/Dash/Grafana

4️⃣ Mobile Optimization & Deployment

Convert trained ML models to mobile-friendly formats (TensorFlow Lite, ONNX, PyTorch Mobile).

Build lightweight, responsive mobile interface.

Offline-first deployment for remote, resource-constrained areas.

📈 Key Features

🌿 Detects two main tea leaf diseases.

🌡 Monitors environmental conditions in real-time.

📊 Dashboard shows disease detection + environmental trends.

🤖 AI-driven recommendations for treatment/intervention.

📱 Mobile-ready & cost-effective for smallholder farmers.

🌍 Supports local languages and sustainable agriculture practices.
