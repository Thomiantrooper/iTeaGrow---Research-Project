# iTeaGrow - Research-Project
🌱 Research project focused on enhancing tea cultivation in Sri Lanka through data-driven insights, monitoring, and technological innovation to improve yield and sustainability.


Component 1
🍃 The Tea Leaf Quality Assessment & Environmental Monitoring System is a one-year research project aimed at developing an AI-powered, non-destructive solution for early detection and monitoring of tea leaf diseases in Sri Lanka. The system captures high-resolution images of tea leaves using handheld or remote cameras and applies computer vision and deep learning techniques to detect and classify two main diseases, providing disease-specific treatment recommendations. 🌿 In parallel, compact IoT sensors monitor environmental parameters such as temperature, humidity, light intensity, and soil moisture in real time, streaming this data to a cloud or local system for continuous logging and analysis. 📊 An intuitive dashboard visualizes both leaf health and environmental trends, enabling plantation managers to make informed decisions on irrigation, fertilization, and treatment. The trained machine learning models are optimized for mobile and edge deployment, ensuring real-time performance even in remote, resource-constrained areas, and the system is designed to be cost-effective, sustainable, and localized in Tamil and Sinhala for smallholder farmers. 🤖 Key technologies include TensorFlow/Keras or PyTorch for deep learning, OpenCV/PIL for image processing, Raspberry Pi/Arduino for sensors, MQTT/HTTP for data streaming, and Streamlit/Dash/Grafana for dashboard visualization. The project combines AI, IoT, and mobile accessibility to create a holistic, tech-driven solution for improving tea plantation productivity and disease management. 🌱
