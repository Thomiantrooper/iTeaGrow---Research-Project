Research Domain

An undergraduate research initiative applying AI, IoT, and Explainable ML to the Sri Lankan tea industry.

System Objectives

  • Enable early detection of disease and environmental/soil-related stress using multi-sensor fusion.
  • Reduce subjectivity in leaf maturity assessment and yield forecasting via computer vision.
  • Provide transparent, data-backed tea powder grading and valuation to replace manual auctions.
  • Support rural deployments through an edge-driven, hybrid system architecture.

Technical Innovations

  • Explainable AI (XAI): Grad-CAM heatmaps highlight prediction regions to improve farmer trust.
  • Edge ML: Optimized models for low-power IoT inference.
  • Hybrid Approach Hybrid cloud connectivity via GSM for remote sensing.
  • Localization: Full Sinhala, Tamil, and English UI support.

The iTeaGrow Stack

Integration of high-performance hardware, deep learning, and cloud infrastructure.

Hardware & IoT

  • ESP32 & SIM800L GSM module
  • NEO-6M GPS & NPK/pH Sensing
  • Multi-depth Environmental Moisture Telemetry
  • Solar–Battery Hybrid Power Management

Machine Learning

  • YOLOv8n (Vision Inference)
  • Random Forest & XGBoost (Tabular)
  • TensorFlow Lite & OpenCV (Mobile)
  • XAI Integration (Grad-CAM & SHAP)

Cloud & Mobile

  • Frontend: React Native
  • Database: SQLite & Firebase
  • Backend: Node.js & Google Cloud
  • Analytics: Python (Pandas/Scikit)
